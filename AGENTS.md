## Обзор проекта

Это Python-проект для скачивания видео с UN WebTV, загрузки на Rutube и генерации транскрипций/саммари. Платформа управляет:
- Извлечением URL видео со страниц ООН
- Загрузкой видео-сегментов через ffmpeg
- Загрузкой видео на Rutube
- Транскрибацией аудио и генерацией саммари
- SQLite-базой данных для хранения метаданных видео, транскрипций и ссылок на Rutube

### Структура сетевых ресурсов
```
\\server\share\video\
├── un\              -- скачанные видео с ООН
├── rutube\          -- видео, загруженные на Rutube
└── transcriptions\ -- текстовые файлы транскрипций
```

## Принципы структуры кода (для рефакторинга)

### Модульность и размер кода
- **Один файл** = максимум 150 строк кода
- **Одна функция** = максимум 30 строк кода
- Если превышено — выноси логику в отдельный модуль или вспомогательную функцию

### Документация
- Каждая функция имеет docstring с описанием параметров и возвращаемого значения **на русском языке**
- Сложная логика комментируется с объяснением **«почему»**, а не **«что»** делает код

### Управление изменениями
- При значимых правках и завершении фаз развития проекта обязательно вносить изменения в файлы:
  - `FEATURES.md` — описание новой функциональности
  - `AGENTS.md` — актуализация правил и рабочих процессов

## Руководство по стилю кода

### Общие соглашения
- Следуйте существующим паттернам кода в репозитории
- Используйте **русский язык** для комментариев и сообщений логов (в соответствии с существующей практикой)
- Делайте функции сфокусированными и модульными (пример хорошего подхода — `parser.py`)

### Импорты
- Сначала стандартная библиотека, затем сторонние, затем локальные модули
- Группируйте по порядку: builtins → external → local
- Используйте явные импорты (избегайте `from module import *`)

```python
# Правильно
import logging
import os
import sys
from datetime import datetime

import requests
from bs4 import BeautifulSoup
import pandas as pd

from meta import VideoInfoExtractor, DataSaver
```

### Форматирование
- Длина строки: 100 символов (мягкое ограничение)
- Используйте f-строки для форматирования
- Отступы: 4 пробела (без табуляции)
- Одна пустая строка между определениями верхнего уровня

### Именование
- **Функции/переменные**: snake_case (`def download_video`, `video_url`)
- **Классы**: PascalCase (`class SeleniumDownloader`)
- **Константы**: UPPER_SNAKE_CASE
- **Приватные функции**: префикс с подчёркиванием (`_internal_helper`)

### Типизация
- Строгая аннотация типов не обязательна, но рекомендуется в сложных местах
- Документируйте типы возвращаемых значений в docstring при сложной логике

### Docstrings
Используйте стиль Google или простые docstring **на русском языке**:

```python
def extract_video_length(soup):
    """
    Извлекает длину видео из блока div.

    :param soup: Объект BeautifulSoup, содержащий HTML-структуру
    :return: Строка с длиной видео
    """
```

### Обработка ошибок
- Используйте блоки try/except для операций, которые могут завершиться с ошибкой
- Логируйте ошибки с соответствующим уровнем (logger.error для критических сбоев)
- Предоставляйте информативные сообщения об ошибках

```python
try:
    response = requests.get(url)
    response.raise_for_status()
except requests.exceptions.RequestException as e:
    logger.error(f"Ошибка при загрузке страницы: {e}")
    return []
```

### Логирование
- Используйте модуль logging, а не print
- Настраивайте логирование на уровне модуля:

```python
import logging

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s - %(levelname)s - %(message)s",
    handlers=[logging.StreamHandler()]
)
logger = logging.getLogger(__name__)
```
